# Panco · Embalagem Celebration Origami × 75 LAB

Apresentação da embalagem de panettone **Celebration Origami** (PAN003): antiprisma com vincos curvos, hot stamping dourado com relevo, três sabores (Brownie, Banoffee, Tiramissu).

Link: https://projetos.75lab.com.br/panco-celebration-origami-75lab/

Feita no **modo cleitinho de apresentar**: deck da agência (`../ype-mpv-2027-75lab/assets`) + telas próprias com 3D ao vivo (three.js):
- tela 7: estados de câmera percorridos pelo Avançar/Voltar;
- tela 11: pilhas girando, com ampliar;
- tela 13: montagem fiel à faca (simulação de dobra), slider de scrubbing, monta sozinha ao entrar;
- tela 16: AR (GLB/USDZ) girando, com QR.

Montar: `python3 fonte/montar.py`. Imagens 3D estáticas: `fonte/renders.html`. AR: `fonte/ar-build.html`.
